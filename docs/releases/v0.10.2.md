# costcrew v0.10.2

The console and its image are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The v0.10.1 image was built with Go 1.27.3. No route, flag, setting, file format or stored state changes.

Tag: `v0.10.2`. The image is `ghcr.io/taipanbox/costcrew:v0.10.2`. There is no moving tag (no `latest`, no `main`).

## Changed since v0.10.1

- #174, `build: Go 1.27.4 for GO-2026-6859`. The `toolchain` line in `go.mod`, the CI `go-version` and the build image in the `Dockerfile` (`golang:1.27.4-alpine`, pinned by digest) move to Go 1.27.4, and the gate anchors that named the old pin move with them.
- #173 and #165, dependency updates: `github.com/aws/aws-sdk-go-v2` 1.47.4 to 1.47.6, `aws-sdk-go-v2/config` 1.33.10 to 1.33.14, `aws-sdk-go-v2/service/bedrockruntime` 1.63.7 to 1.63.10, `github.com/go-jose/go-jose/v4` 4.1.6 to 4.1.8, `modernc.org/sqlite` 1.61.0 to 1.61.1 and `google.golang.org/grpc` 1.84.0 to 1.85.0.
- #164, the `golang` base image digest moves (superseded by the 1.27.4 pin in #174).
- #172, the actions in the workflows move to newer pinned commits (`docker/login-action` 4.8.0, `sigstore/cosign-installer` 4.1.3, `github/codeql-action/upload-sarif` 4.39.3).

## Upgrade

Pull `ghcr.io/taipanbox/costcrew:v0.10.2` and restart. No configuration or data changes. To roll back, run v0.10.1 again.
