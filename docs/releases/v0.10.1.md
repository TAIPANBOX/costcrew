# CostCrew 0.10.1

A patch. The image is built with Go 1.27.3, which fixes [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809) in `crypto/x509`, on agent-stack-go v2.0.2. The `/cadence` page now says what the platform does.

## Upgrade

1. **Pin `ghcr.io/taipanbox/costcrew:v0.10.1`.** Nothing in the configuration changes.
2. **The `/cadence` page describes the clock as it is** (#170). The cluster's CronJob fires every day and a single-box install has no routine for it. What stands between firing and spending is the switch on that page.

## What changed

- Go 1.27.3 for GO-2026-6809 (#160), agent-stack-go v2.0.2 (#163), the gomod group (#159), the actions group (#161).
- CI runs the gate and its teeth as parallel jobs, the teeth in twelve shards balanced by measured seconds (#162).
- README and invariant text: what the supervisor applies without a second stamp (#166), the tests badge, the image history and the stack diagram (#167), the crew CronJob is not suspended (#169).
