# CostCrew 0.3.0

The crew's supervisor decides what its job description lets it decide, the
owner's thresholds are written down, a gateway can no longer be silently
bypassed for OpenRouter, a stopped task keeps the charge it settled, and an
admin who answers for an owner must say why. Behaviour changes, so read the
upgrade notes. This release was approved by the owner.

## What changed (costcrew#85 to #89)

- **The supervisor selects among the analysts' own options inside T.anomaly
  (#85, invariant 53).** Before, every option in a class the analyst owns went
  to the owner as a decision request whatever its figure, although the
  supervisor's job description lists `option.select`. Now the supervisor
  applies an analyst-class option itself when the figure is at or under
  T.anomaly, with `decided_by` staying `supervisor`. Owner-owned classes, a
  contradiction between two analysts, and anything over T.anomaly still go to
  the owner. A second option on an anomaly the same pass already settled is
  carried, not applied.
- **OpenRouter goes through the OpenAI-shaped gateway or is refused (#86,
  invariant 54).** A configured gateway used to be ignored for `openrouter`
  and `bedrock`, so a run said "calls go direct" and made them. New setting
  `-gateway-openai` / `COSTCREW_GATEWAY_OPENAI` names the OpenAI-shaped
  gateway (console, runner and bench). `deliver.Gateway.RouteFor` is the one
  place that decides where a call goes: no gateway at all, direct as before;
  a gateway that fronts the engine's wire, that gateway; any gateway
  configured and none that fronts the engine, refused before any request is
  built. The OpenAI door carries the same `x-fuse-*` headers and reads the
  same settlement headers as the Anthropic one, and a 402 stops the run.
- **A stopped task keeps its settled charge (#86, invariant 55; fixes
  costcrew#82).** A run stopped mid-task showed 0.00 on the board even though
  the gateway had billed its earlier rounds. A round that failed without
  answering no longer erases the settled ones, the error path records the
  charge, and the headline leads with the gateway's figure and says so when
  the gateway's own total is higher than what reached the runner.
- **The owner decided the thresholds (#87, invariant 56).** T.anomaly goes from
  USD 5,000 to USD 2,500 and T.urgent from USD 25,000 to USD 12,500. The other
  five keep their values. All seven now carry the decided marker, and the
  provenance vocabulary in `roles.yaml` is closed to `@claude`, `@decided
  YYYY-MM-DD` and `@measured <how> YYYY-MM-DD`, checked at load and by
  `scripts/roles-are-bound.sh`.
- **Job descriptions are complete (#88, invariant 57).** Eight analyst
  families had an empty `decides_alone` and five an empty `hands_up`; the class
  lists are now written from the prose, and the roles gate refuses an empty
  list unless the family carries a reasoned exemption (five for
  `decides_alone`, two for `hands_up`, each named). The sixth clause of the
  never list, "act on a task somebody blocked", is bound to the runner's own
  test.
- **An admin answering for an owner gives a reason (#89, invariant 58).** The
  emergency path stays, with no class check, but it is no longer silent: the
  answer needs `behalf_reason` (trimmed, at most 500 bytes, refused when over,
  plain text only). It is recorded on the option, in the journal, on the bus
  (`answered_by`, `answered_as`, and for an admin's answer for someone else
  `on_behalf_of` and `on_behalf_reason`) and on the cards. A person's refusal
  is now journaled too (`option_refused`, severity `low`).

Housekeeping since 0.2.2: agent-stack-go v1.0.2 (#80), CI action bumps (#81,
#83) and a README note that costcrew#69 is closed by v0.2.1 (#84).

## Upgrade notes

- **Thresholds halved.** From 0.3.0 the supervisor stops applying options
  above USD 2,500 and carries them to the owner. More decision requests will
  reach the owner than under 0.2.2 for the same work. A decision request
  already built under the old figure is not re-evaluated; only options
  supervised from now on meet the new one. T.urgent is not read by any code,
  so its halving changes the card and the supervisor's text only. The
  severity bands in `internal/anomaly` and `internal/stack` (critical at USD
  5,000) are untouched and may now sit above T.anomaly.
- **With any gateway configured, an engine no configured gateway fronts is
  refused, not run direct.** That is bedrock always, openrouter with only
  `-gateway`, and anthropic with only `-gateway-openai`. A run is refused as a
  whole before its first call, naming the engine counts and the setting to
  use; narrow it with the runner's `-engine` filter, or set the missing
  gateway. With no gateway at all nothing changes. An Anthropic-wire gateway
  given as `-gateway-openai` receives an OpenAI body and answers 400 itself:
  nothing checks which upstream is behind each URL.
- **New setting** `-gateway-openai` / `COSTCREW_GATEWAY_OPENAI`, declared in
  `components.json`. Stack launchers that run OpenRouter engines behind
  TokenFuse need a gateway on `TOKENFUSE_WIRE=openai` and this setting.
- **An admin answering for another owner must supply a reason.** Any script
  or client that posts the option apply or refuse form for an owner who is not
  the signed-in admin needs the `behalf_reason` field. The owner's own answer
  needs none. Two nullable columns (`on_behalf_of`, `behalf_reason`) are added
  to `artifact_options` by `crew.EnsureOptionBehalf` when the console starts; old answers read back as
  before. A person's refusal now emits `option_refused` on the bus at severity
  `low`, a second producer of an event type the save-time gate already emitted.
- **Restricted analysts now owe options.** A restricted sustainability-analyst
  that "proposes only" must now end a deliverable with an options block naming
  `explainer.publish`, and one without is returned at save time. The prompt
  packet and card show new "You may decide alone" and "You hand to the
  supervisor" lines for the families that gained lists.
- A 0.2.2 installation moves to 0.3.0 by moving the image tag.

## Not proven

- The console buttons and the runner's `-supervise` mode were not run end to
  end; the supervisor pass is tested through `finops.Supervise`. The new
  decision page and "Answered" panel were read as rendered HTML, not opened in
  a browser.
- No real TokenFuse was run on `TOKENFUSE_WIRE=openai` in front of OpenRouter;
  the fakes send what `proxy.rs` sends, as read from its source. A call the
  gateway settled whose response never reached the runner shows only as a gap
  the headline names. A task that fails inside `saveDraft` before its charge
  is recorded still books nothing on the board.
- The nine class mappings in the job descriptions are readings of prose; two
  (deep-analysis `agent.*`, migration-watch `anomaly.accept`) are the least
  certain. The roster's analysts were not run live against the new prompt
  lines. Converting an exemption to a class is the owner's call.
- A task blocked while its call is already in flight still gets its
  deliverable written; the blocked-task bound acts at selection. The other
  five never clauses are not bound to a test.
- Nobody is told that someone answered for an owner beyond the card and the
  journal entry, and no class check was added on that path. The envelope's own
  `on_behalf_of` chain is not populated.
- An analyst's two agreeing options on one anomaly now give one applied and
  one carried option (a confirmation request to the second analyst's owner).
- While producing red-first evidence for #86, six tests made real HTTPS
  requests to openrouter.ai with a stub key and got 401, no spend; later runs
  blocked the network, and the tests that ship cannot reach a provider.
- Coverage was not re-measured for #87 to #89.
