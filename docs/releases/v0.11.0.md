# costcrew v0.11.0

A minor. It adds the Azure Cost Management FOCUS reader, makes demo mode spend nothing, and fixes two import paths that could lose or refuse data. It also prices one OpenRouter row to what its providers charge. The routes, flags and stored file formats keep their names.

Tag: `v0.11.0`. The image is `ghcr.io/taipanbox/costcrew:v0.11.0`. There is no moving tag (no `latest`, no `main`).

## Upgrade

1. **Pin `ghcr.io/taipanbox/costcrew:v0.11.0` and restart.** No configuration key is renamed or removed.
2. **Demo mode refuses the plan-ask.** With `COSTCREW_DEMO` set, the plan-ask refuses before any model call, so nothing spends the owner's budget (invariant 113).
3. **The generated estate is replaced only by a kept spend import.** `-focus-replace-generated` wipes the generated estate after the export files are read, and only when the import holds spend (invariant 114).

To roll back, run v0.10.2 again.

## What changed since v0.10.2

- #182, `feat(connectors): Azure Cost Management FOCUS reader`. Azure's FOCUS 1.0 export joins the cloud FOCUS engine beside AWS data exports and the GCP billing export (invariant 112). A month-to-date export holds the whole month on each run, so only the newest run per period is read, and once it lands the rows of its other runs are removed. The README counts Azure among the built connectors and documents `COSTCREW_BEHIND_TLS`, `COSTCREW_SIGNUP_CODE` and `COSTCREW_DEMO`.
- #183, `fix(connectors): an empty export folder reads nothing; no spend replaces nothing`. An existing export folder with no files yet reads zero files, where it used to refuse the import. A missing folder, or a folder of links only, is still refused. The estate is seeded again only into a store that holds no `ai_calls` rows (invariant 114).
- #181, `fix(engines): OpenRouter Sonnet 5 row at 2.00 / 10.00`. The row for `openrouter/anthropic/claude-sonnet-5` now carries the price its five OpenRouter providers listed on 2026-11-22. The row had read 2.20 / 11.00, a price none of them charged. A red-first test covers it.
- #177, `deps: agent-stack-go v2.0.3 (Go 1.27.4 rebuild)`. The shared agent-stack library is rebuilt on Go 1.27.4, the release toolchain that fixes GO-2026-6859 in `net/http`.
