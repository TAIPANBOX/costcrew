Price basis

The gateway prices each call from its price book; a model the book has no price for is priced at the gateway's fallback rate, which can be many times the real price. From the version that adds x_price_basis to its export, each row says which, and this console keeps a fallback-priced amount out of spend and shows it here.

Forwarded under identity warn mode

With TOKENFUSE_IDENTITY_STRICT=warn the gateway lets a call through when the agent id it carries does not belong to the credential that sent it, and files the call and its spend under the id it claimed. From TokenFuse 1.8.0 the export says so on the row (x_identity_reason), and this panel reads it: such a call is real spend, and it is counted in every figure above, but nobody proved which agent made it.
