A guard is monthly, so “past guard” is measured against this month alone. The last column is every task this owner's agents have ever been charged for, which is a different question and is not comparable to the guard beside it.

An agent that is transferred brings its whole record with it, so the last column can move between people without anyone having spent anything: a charge records which agent ran, never who owned it that day. Closed work keeps the desk it was charged to, so the chargeback and budget figures do not move when an agent changes hands.
