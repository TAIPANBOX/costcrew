These figures are what each person authorised, taken from the owner recorded on every charge, so they do not move when an agent does. A transfer splits an agent's record at the handover: work still open goes to the new owner, work already closed stays with whoever signed for it. Somebody who has given every agent away therefore still appears here, against what they spent, with no agents beside it. Closed work also keeps the desk it was booked to, so the chargeback and budget figures never move when an agent changes hands.
