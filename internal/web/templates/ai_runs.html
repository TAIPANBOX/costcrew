Runs

One row per run the gateway's rows name, for {{.Month}}: what it spent, every model it called and each model's share of that spend, in the order it first called them, and how it ended as far as the gateway's own rows show. A run that started on one model and finished on another is one run with two models in it; naming it by its last model names it by the model that may have done the least of its work.
